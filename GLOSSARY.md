# Portfolio Domain Model

Ubiquitous language and domain model for Mahmoud Almodalal's engineering portfolio and project showcase.

## Language

**Featured Project**:
A top-tier production or commercial case study displayed in the primary grid with rich architecture facts, real-world constraints, and measurable impact.
_Avoid_: Highlight, showcase item, hero card

**Archive Project**:
A focused engineering entry in the secondary index demonstrating specialized depth across backend, systems, and experimentation.
_Avoid_: Minor project, side project, other work

**Visual Lightbox**:
An accessible in-page overlay viewer that displays high-resolution project mockups and dashboard screenshots with zooming and details without forcing external navigation.
_Avoid_: Image popup, modal window, preview redirect

**2Wash**:
An on-demand car care and wash coordination marketplace in Saudi Arabia connecting vehicle owners with certified partner centers, built on Django REST, Next.js, PostGIS, and automated financial settlements.
_Avoid_: Car wash app, cleaning site, wash booking script
